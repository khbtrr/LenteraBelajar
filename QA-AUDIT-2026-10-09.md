# Laporan QA LenteraBelajar

Tanggal: 9 Oktober 2026. Baseline: working tree saat pemeriksaan, termasuk perubahan lokal dan file untracked. Acuan: README.md, DESIGN.md, schema Prisma, perilaku implementasi, serta instruksi AGENTS.md. Pengguna memilih antislop selama pemeriksaan dan seluruh codebase/dokumentasi sebagai baseline.

**Kesimpulan QA: belum layak dirilis.** Build produksi gagal dan terdapat kelemahan isolasi sekolah, kebocoran data autentikasi/kunci ujian, serta inkonsistensi nilai. Tidak ada perbaikan kode aplikasi atau perubahan database dalam audit ini. Laporan ini mencatat 56 kelompok temuan; satu kelompok dapat mencakup beberapa fungsi dengan penyebab yang sama.

## Metode, hasil pemeriksaan, dan batas bukti

Pemeriksaan mencakup autentikasi/middleware, pengelolaan platform/sekolah/pengguna, akademik/cohort/course, materi/tugas/presensi/forum, pesan/notifikasi/calendar/gamification, CBT/proctor/remedial/bank soal, gradebook/leger/analisis, upload/import Moodle, konfigurasi deployment, dan komponen UI terkait. Aset SVG/vendor tidak diaudit sebagai kode bisnis. Ini bukan jaminan bahwa setiap jalur runtime atau seluruh kemungkinan bug telah ditemukan.

| Pemeriksaan | Hasil |
| --- | --- |
| `npm.cmd test` | PASS: 18 file, 156 test lulus |
| `npm.cmd run lint` | Selesai: 0 error, 21 warning |
| `npx.cmd tsc --noEmit` | FAIL: 12 error TypeScript |
| `npm.cmd run build` | FAIL pada typecheck; kompilasi bundle berhasil sebelum tahap tersebut |
| Probe modul produksi dengan dependency mock | Mengonfirmasi query/mutasi rentan pada course, pengguna, assignment sekolah, enrollment, percakapan, notifikasi, tahun ajaran, approval request, dan bulk presensi |
| Browser, DB nyata, HTTP exploit, load test | Tidak dijalankan; jangan menganggap temuan telah direproduksi end-to-end |

Probe memakai transpile TypeScript modul produksi ke VM dan dependency mock, tanpa menulis ke DB. Temuan concurrency berdasarkan urutan operasi dan constraint schema, bukan stress test. Temuan UI berdasarkan markup/CSS dan perhitungan kontras, bukan screenshot, pengukuran viewport, atau uji screen reader. Build juga mengeluarkan empat warning tracing filesystem dan deprecation middleware.

Prioritas: **P1** menghalangi rilis karena keamanan, integritas data/nilai, atau build; **P2** bug fungsional/ketahanan yang perlu diperbaiki; **P3** ketidaksesuaian dokumentasi, desain, atau proses. Prioritas merupakan penilaian QA, bukan skor CVSS.

## Pertanyaan QA yang harus dijawab sebelum sign-off

Pertanyaan awal tentang scope dan waktu antislop sudah dijawab pengguna. Keputusan rilis lanjutan yang perlu dikunci setelah perbaikan:

- Apa satu sumber nilai resmi antara Grade, QuizAttempt, gradebook, leger, dan export? Rekomendasi: satu kebijakan agregasi berdasarkan resource ID, skor ternormalisasi, attempt terpilih, dan remedial yang menggantikan induk dengan cap KKM.
- Apa hasil yang diharapkan saat ujian dihentikan, koneksi terputus, atau deadline lewat? Rekomendasi: finalisasi idempoten pada server memakai jawaban tersimpan, essay tetap menunggu koreksi, dan grace period terdokumentasi.
- Siapa yang boleh membuka course lintas sekolah dan memberikan assignment sekolah? Rekomendasi: SUPER_ADMIN mengatur assignment/publikasi lintas tenant; akses peserta memerlukan enrollment atau grant eksplisit.

Audit ini memenuhi permintaan pemeriksaan dan laporan, bukan persetujuan rilis. Sign-off memerlukan penutupan temuan prioritas tinggi serta pengujian integrasi/browser dengan lingkungan test yang terisolasi.
